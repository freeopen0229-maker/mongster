# 바로 실행하는 Development 체험

MainGame.unity 진입점은 유지한다. Development Build이고 실제 로그인 제공자/NetworkConfig가 준비되지 않았을 때만 OfflineGamePreview로 들어간다. 로그인 설정이 완료된 경우 기존 온라인 진입 흐름을 그대로 사용한다. Release에서 오프라인 체험으로 자동 전환하지 않는다.

화면에 개발용 오프라인 체험과 온라인 계정 별도 저장을 상시 표시한다. PreviewSave와 PreviewRules는 온라인 PetState/RuntimeManager/IPetGateway에 값을 전달하지 않는다. 로컬 기록은 Mongster.OfflinePreview.v1 한 키에 저장하며 서버 계정으로 이관하지 않는다. 기존 서버 pending RequestId/재화/토큰은 건드리지 않는다.

## 플레이

- 설치 후 실행하면 늘귀의 정원이 나온다. 먹이, 교감, 씻기, 놀이, 휴식으로 수치를 바꿀 수 있다.
- 먹이 구매는 체험 전 5개를 사용한다. 초기 전40, 먹이5.
- 탐험은 활력10을 소비한다. 햇살 숲부터 시작하고 성공하면 다음 지역이 열린다. 총3개 지역.
- 조이스틱 이동, 공격 버튼 근접 범위 공격, 회피 버튼 짧은 돌진/무적. PC는 방향키/WASD, Space 공격, LeftShift 회피.
- 적을 모두 처치하면 체험 전/경험치를 받고 레벨이 오른다. 쓰러지면 집에서 회복 후 재도전한다.
- 앱 재시작 시 체험 기록을 유지한다. 휴대폰에서 직접 화면/터치/재시작 검증은 별도 필요하다.

9개 기존 아기 원화 파츠를 표시하고, 필드·적·타격 입자는 Unity SpriteRenderer로 구성한다. 로그인 서버 테스트 UI 대신 실제 조작 가능한 개발용 루프를 제공하기 위한 변경이다. 새 성체/126종 아트나 상용 게임 전체 완성을 뜻하지 않는다.

검증: OfflinePreviewProbe로 먹이 소비/중복 조건, 잠긴 지역, 활력 소비/회복, 승리 보상/레벨, 먹이 구매, 손상 저장/시간 제한을 검사한다. 기존 서버/경제 RequestId 검사는 그대로 유지한다. Android 네이티브 컴파일과 APK 결과는 해당 Actions 실행에서 확인한다.
